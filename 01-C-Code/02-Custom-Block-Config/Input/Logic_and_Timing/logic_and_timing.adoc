# Overview

This example demonstrates how edge-detection and timer functions can be configured to improve logical readability in generated diagrams.

The C code uses separate process functions so that each logic/timing block can be inspected independently.

## C-Code example

----
include::logic_and_timing.c[]
----

## Configuration example

[source,xml]
----
<function name="edgeRising_V2" imageURI="images/edge_rising.jpg" comment="Rising edge" >
    <argument index="0" name="in" portLocation="LEFT"/>
</function>

<function name="edgeFalling_V2" imageURI="images/edge_falling.jpg" comment="Falling edge" >
    <argument index="0" name="in" portLocation="LEFT"/>
</function>

<function name="timer_V2" imageURI="images/timer.jpg" comment="Timer" >
    <argument index="0" name="in" portLocation="LEFT"/>
    <argument index="1" name="duration" portLocation="TOP"/>
</function>
----

Configuration semantics:

- *LEFT* is used for the main signal input.
- *TOP* is used for timing parameters such as *duration*.
- Separate functions and icons make the logic/timing intent easier to identify.
