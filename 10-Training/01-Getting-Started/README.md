# Training: Getting Started with EHANDBOOK Container-Build

Welcome to the EHANDBOOK Container-Build (EHB-CB) training! 👋

This training is for **customer-facing engineers**, such as field application engineers, pre-sales and solution engineers, technical consultants and support engineers. Its goal is that you understand how EHB-CB works, so you can confidently demonstrate it, set it up and support customers in their own projects.

This folder is the starting point for a hands-on example that grows step by step during the training. We begin with a small Simulink model of a simplified **ABS (Anti-lock Braking System) slip controller** and turn it into an EHANDBOOK container. In later steps we add more sources, configuration, styling and customer-specific branding. These are the kinds of tasks you will meet in real customer engagements.

Along the way you will learn:

- how EHB-CB turns source artifacts (models, code, documents) into an EHANDBOOK container
- which inputs, command-line options and configuration files control the build
- how model structure, signals and calibration parameters (e.g. `ABS_SlipRef`, `ABS_HydrLagTb`) appear in the output, which is what customer calibration engineers will work with
- how to adapt the result to a customer, e.g. with a custom title page

No prior experience with EHB-CB is needed. Just follow along, build often and explore the result in EHANDBOOK-NAVIGATOR. Let's get started! 🚀
