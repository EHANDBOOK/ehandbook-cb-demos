# Overview

This example demonstrates C-Code access/memory primitives that are visualized as dedicated icon blocks.

The C code separates the access/memory operations into focused process functions for easier inspection.

Covered blocks:

- *GetMember*
- *GetAddr*
- *GetIndexDeref*
- *GetDeref*
- *SetMember*
- *SetDeref*
- *SetIndexDeref*
