# Overview

This chapter explains configuration options for C function arguments in 'CCodeConfig.xml'.

The examples are intentionally minimal and structured in two groups:

1. Port location variants only ('TOP', 'LEFT', 'BOTTOM', 'INVISIBLE')
2. Flag behavior examples ('isInstance', 'isReference')

Semantics used in this chapter:

- 'isInstance="true"': the argument is used as instance name of the block.
- 'isReference="true"': the argument is passed as reference.

## 1) Port location variants

Port location controls where an argument's port appears on the block.
By default, all arguments are displayed as input ports on the left.
These examples show how to override this default placement.

### Without configuration

[source,c]
----
void process1_port_default() {
    float in;
    float out = portTop_raw(in);
}
----

## 2) 'isInstance' and 'isReference' examples

These examples also use one argument to isolate the flag behavior.

### Without configuration

[source,c]
----
void process1_instance_name() {
    float instanceId;
    float out = instanceName_raw(instanceId);
}

void process1_reference_arg() {
    float refValue;
    float out = referenceArg_raw(&refValue);
}

void process1_instance_reference() {
    float instanceRef;
    float out = instanceReference_raw(&instanceRef);
}
----
