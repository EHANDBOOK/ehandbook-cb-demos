# Overview

This example demonstrates how saturation and rate-limiter functions can be configured so the resulting diagrams expose limit and slope parameters in a consistent way.

The C code uses separate process functions so that saturation and rate limiting can be inspected independently.

## C-Code example

----
include::limits_and_rate_limiter.c[]
----

## Configuration example

[source,xml]
----
<function name="saturation_V2" imageURI="images/SrvF_Limit.png" comment="Saturation" >
    <argument index="0" name="x" portLocation="LEFT"/>
    <argument index="1" name="min" portLocation="TOP"/>
    <argument index="2" name="max" portLocation="TOP"/>
</function>

<function name="rateLimiter_V2" imageURI="images/SrvF_Limit.png" comment="Rate limiter" >
    <argument index="0" name="in" portLocation="LEFT"/>
    <argument index="1" name="rise" portLocation="TOP"/>
    <argument index="2" name="fall" portLocation="TOP"/>
</function>
----

Configuration semantics:

- Main signal paths are mapped to *LEFT* ports.
- Calibration constraints (*min*, *max*, *rise*, *fall*) are mapped to *TOP* ports.
